Eixo 1 • 96 Horas Formativas

Fundamentos da Programação e Lógica

O alicerce estrutural de todo programador. Aqui você aprende a pensar algoritmicamente antes de usar linguagens complexas.

UC 1 48 Horas

Desenvolver Algoritmos

Construção do raciocínio lógico sequencial, resolução estruturada de problemas, controle de fluxo e modularização.

O que você vai dominar:
  • Variáveis, tipos de dados e operadores aritméticos/lógicos;
  • Estruturas de decisão (se/senão) e de repetição (enquanto/para);
  • Funções, procedimentos, passagem de parâmetros e retorno.
Lógica PuraPortugolFluxogramas
UC 2 48 Horas

Programar em POO

Transição da lógica sequencial para a Programação Orientada a Objetos, padrão dominante da indústria de software.

O que você vai dominar:
  • Classes, instâncias, atributos e métodos construtores;
  • Os 4 Pilares da POO: Encapsulamento, Herança, Polimorfismo e Abstração;
  • Instalação e configuração de IDEs profissionais de código.
Java / C#VS Code / EclipseParadigma OO

Eixo 3 • 168 Horas Formativas

Engenharia de Dados, NoSQL & Analytics

Aprenda a modelar, consultar, integrar e transformar dados brutos em decisões inteligentes para as empresas:

UC 7 72h

Banco Relacional (SQL)

Modelagem conceitual e lógica: Diagrama Entidade-Relacionamento (DER), integridade referencial e normalização.

  • Comandos DDL (CREATE, ALTER, DROP);
  • Comandos DML (SELECT avançado com JOINs, INSERT, UPDATE, DELETE);
  • Triggers, Stored Procedures e Views.
MySQLPostgreSQLSQL
UC 14 36h

Banco Não Relacional

Arquitetura de dados para alta performance e flexibilidade: Bancos orientados a documentos JSON e coleções.

  • Estruturação e serialização de dados com JSON e XML;
  • Criação de coleções dinâmicas NoSQL;
  • Operações completas de CRUD não-relacional.
MongoDBJSONNoSQL
UC 10 60h

Relatórios & Análise de Dados

Coleta, tratamento estatístico e visualização inteligente de dados com Python para apoiar a diretoria das empresas.

  • Extração de bases públicas (Kaggle e Brasil.io);
  • Tratamento de dados com Pandas e NumPy;
  • Geração de gráficos, tabelas e relatórios executivos.
PythonPandasNumPy
Eixo 4 • 216 Horas de Web Full Stack

Desenvolvimento Web Completo

Construção integral de sistemas modernos na web, conectando a interface no navegador com servidores na nuvem:

UC 13 108 Horas

Front-End Web

A parte visual que os clientes utilizam no navegador: aderente aos padrões internacionais W3C, acessível e responsiva.

Competências Desenvolvidas:
  • HTML5 Semântico: Estruturação com tags modernas e acessíveis;
  • CSS3 Moderno: Flexbox, CSS Grid, estilizações visuais e animações;
  • JavaScript: Programação no cliente, eventos dinâmicos e consumo de APIs;
  • Frameworks Front-End: Bibliotecas de componentes e produtividade.
HTML5CSS3JavaScriptBootstrap
UC 15 108 Horas

Back-End Web

A inteligência que roda no servidor seguro: regras de negócio, autenticação, geração de APIs REST e conexão com bancos de dados.

Competências Desenvolvidas:
  • Padrão Arquitetural MVC: Model, View, Controller para códigos organizados;
  • Criação e Consumo de APIs REST: Conectando web, mobile e desktop;
  • Segurança & Sessões: Login seguro, cookies, tokens e proteção contra invasões;
  • Publicação & Deploy: Configuração de servidores locais e na nuvem.
Node.js / Java / PHPMVCAPIs RESTDeploy Cloud

Prática Diária

Programação é uma habilidade prática. Não se limite apenas ao laboratório: refaça os exercícios em casa e teste novas ideias.

GitHub desde o 1º Dia

Crie seu perfil no GitHub imediatamente. No mercado de tecnologia, o seu portfólio de códigos públicos é o seu currículo vivo.

Nunca Guarde Dúvidas

O laboratório é o ambiente seguro para errar, receber feedback e aprender. O professor e os colegas estão aqui para apoiar.

Networking & Trabalho Colaborativo

Os colegas que sentam ao seu lado hoje serão seus futuros sócios em startups, líderes de equipe ou quem vai indicar você para vagas no mercado.
